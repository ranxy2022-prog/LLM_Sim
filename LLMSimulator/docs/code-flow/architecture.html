先看包含，再看共享。
总览展示入口创建的三大对象；设备执行视图重点解释 TopModuleGraph；模型组合树可逐层展开到算子与张量。对象详情会列出成员类型、子对象用途、继承的公共组成和源码位置。
实线表示包含关系，绿色是持有子对象，金色是值成员；虚线表示引用同一个已有对象。shared_ptr 可以被多处持有，所以“子对象”不意味着独占所有权。紫色点线表示创建或临时结果，不是永久成员。
图是源码结构整理，不是实际堆快照。循环创建的层/专家合并展示。模型树保留所有构造分支，当前配置可判断不成立的分支默认折叠；参数相关条件保留文字。
类型索引覆盖自有 src 中完整定义的 class / struct，包括历史遗留对象。标准库、枚举、指针别名不当成新对象；嵌入的 Ramulator 在外部接口处截止。
阅读标记只保存在当前浏览器，可导出备份。源码是生成时快照；更新代码后运行 python3 build_architecture.py --check 可检查是否过期。图中配置数量需随配置手动复核。
